Five gates between you and a bricked drive.

Start stays disabled until every rule passes. Each rule is decided in tested core code, not in the UI, and the tooltip tells you which one is still failing.

  1. probe

    Platform check

    sdftool --info must report an MT1959 controller. MT1939 drives are refused outright.

  2. form

    Form factor

    Slim firmware on a desktop drive, or the reverse, needs an explicit cross-flash acknowledgement.

  3. id

    Firmware identity

    Images are identified by SHA-256 and content scan, never by filename. Downgrades and model mismatches are flagged.

  4. mode

    Flash mode

    Encrypted and boot-loader rawflash are mutually exclusive. Encryption is chosen from the drive and image dates.

  5. confirm

    Typed confirmation

    Type FLASH /dev/sr0 exactly. Dry-run mode prints the full plan without writing a byte.

Same engine, no window.

The binary doubles as a CLI. It plans commands through the same code path as the GUI, and flashing stays a dry run until you pass --confirm.

zsh
$ sdf-flash-gui list
Optical Drives:
  /dev/sr0 HL-DT-ST BD-RE BU40N (1.03) serial=MODJ9TK3546

$ sdf-flash-gui info /dev/sr0
Platform: MT1959=true
Encrypted firmware: false
LibreDrive: PossibleNotEnabled

$ sdf-flash-gui dump /dev/sr0 -o ~/fw-backup
$ sdf-flash-gui flash /dev/sr0 -i BU40N-1.03.bin
# dry run: prints the plan, writes nothing
$ sdf-flash-gui flash /dev/sr0 -i BU40N-1.03.bin --confirm

Install.

Requires MakeMKV, which ships sdftool and makemkvcon. An sdf.bin from the firmware pack is optional but improves probing.

macOS

$ brew install --cask thedavidweng/tap/sdf-flash-gui
  • .dmg Apple silicon
  • .dmg Intel

Windows

Some raw device paths need an Administrator prompt.

  • .msi x64 installer

Linux

Add yourself to the cdrom group to open /dev/sr*.

  • .AppImage x86_64
  • .deb x86_64

Or build from source: cargo build --release. Checksums ship with every release.

Flashing firmware can permanently damage a drive. Dump your current firmware first. This project is not affiliated with MakeMKV, LG, or ASUS.
